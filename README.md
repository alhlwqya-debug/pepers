# Pepers — حساب الخياطين

> تطبيق Android عربي لإدارة حسابات محلات الخياطة، الإنتاج، المصروفات، السجلات الشهرية والتقارير، مع دعم الحسابات السحابية والمزامنة بين الأجهزة.

## عن Pepers

**Pepers** هو تطبيق عربي موجّه لأصحاب محلات الخياطة والخياطين والعاملين فيها. صُمم ليعمل محليًا حتى دون اتصال بالإنترنت، مع إمكانية تسجيل الدخول ومزامنة بيانات الحساب مع Supabase عند توفر الإنترنت.

الواجهة عربية وتدعم **RTL**، ولا يضيف التطبيق بيانات تجريبية أو سجلات وهمية؛ يبدأ الحساب ببيانات فارغة ويستخدم البيانات التي يدخلها المستخدم فقط.

## أهم المزايا

### إدارة المحلات والسجلات
- إدارة أكثر من محل بحساب مستقل لكل محل.
- إعداد نوع التسجيل لكل محل: التسجيل العددي أو التسجيل الفردي.
- إنشاء السجلات الشهرية مع تحديد السنة والشهر وتاريخ البداية.
- تحديد أيام العمل للشهر.
- استعادة آخر شهر مستخدم لكل محل عند العودة إلى التطبيق.
- إنشاء مساعد اختياري أثناء الإعداد الأولي، مع المهمة وتاريخ البداية.
- إدارة قطع العمل وأسعارها.
- تسجيل الإنتاج اليومي والمصروفات والملاحظات.
- البحث والفلترة في السجلات.
- نسخ كميات آخر يوم مسجل إلى أول يوم فارغ.
- نسخ شهر كامل مع الاحتفاظ بإعداداته دون نسخ الكميات القديمة.

### الإعداد الأولي والحسابات
عند إنشاء حساب جديد، ينتقل التطبيق إلى إعداد أولي خاص بالحساب لإنشاء بيئة العمل قبل الدخول إلى السجل:

1. إنشاء المحل ورقم التسجيل.
2. اختيار نوع التسجيل.
3. تحديد السنة والشهر.
4. تحديد تاريخ بداية العمل.
5. تحديد أيام العمل.
6. إنشاء أول مساعد اختياريًا.
7. الدخول مباشرة إلى مساحة العمل.

يتم حفظ حالة الإعداد **لكل حساب**، لذلك لا يُعاد عرض الإعداد الأولي عند تسجيل الدخول إلى حساب سبق إعداده.

الحساب الموجود مسبقًا يستعيد بياناته المحلية وسياقه السابق، ثم يحاول مزامنة بياناته السحابية قبل فتح مساحة العمل.

### تسجيل الدخول والمزامنة
- تسجيل الدخول بالبريد الإلكتروني وكلمة المرور.
- إنشاء حساب جديد.
- تسجيل الدخول باستخدام Google.
- متابعة الاستخدام دون حساب.
- استعادة كلمة المرور عبر البريد الإلكتروني.
- لا يعتمد التطبيق على رمز SMS ذي الستة أرقام.
- استعادة جلسة الحساب عند إعادة فتح التطبيق.
- فصل قاعدة البيانات المحلية حسب معرف المستخدم.
- رفع وتنزيل بيانات الحساب مع Supabase.
- إعادة محاولة المزامنة بعد تجديد جلسة Supabase عند الحاجة.
- تشغيل مزامنة خلفية عند توفر الظروف المناسبة.

> في حال عدم توفر الإنترنت، يستمر التطبيق باستخدام قاعدة البيانات المحلية. فشل المزامنة لا يحذف البيانات المحلية.

### Google OAuth
يستخدم تسجيل الدخول بواسطة Google رابط إعادة توجيه داخلي للتطبيق:

`pepers://auth`

ويستقبل `MainActivity` رابط العودة ويكمل جلسة تسجيل الدخول. يجب أن يتطابق رابط إعادة التوجيه المسموح به في إعداد OAuth/Supabase مع هذا الرابط.

### الحماية
- قفل التطبيق باستخدام بيانات اعتماد الجهاز أو المصادقة الحيوية عند تفعيل القفل.
- دعم البصمة/المصادقة الحيوية حسب قدرات الجهاز.
- الاحتفاظ ببيانات الحساب المحلية بعد تسجيل الخروج.
- عند تسجيل الخروج يتم مسح جلسة المصادقة فقط، مع إبقاء بيانات الحساب المحلية معزولة.

### التقارير وملفات PDF
- إنشاء تقارير PDF من بيانات السجل.
- مشاركة التقرير باستخدام آلية مشاركة Android.
- دعم WhatsApp والبريد وأي تطبيق يدعم مشاركة الملفات.
- استخدام `FileProvider` لمنح التطبيقات المستقبلة صلاحية الوصول إلى الملف.
- عدم الاعتماد على وجود تطبيق مشاركة محدد على الجهاز.

### النسخ الاحتياطي
- إنشاء نسخة احتياطية محلية للبيانات.
- استعادة النسخة عند الحاجة.
- الاحتفاظ بنسخة احتياطية داخلية تلقائية عند تشغيل التطبيق.
- يجب التعامل مع النسخ الاحتياطية باعتبارها بيانات خاصة.

### الإشعارات والعمل في الخلفية
- طلب إذن الإشعارات على Android 13 والإصدارات الأحدث.
- جدولة تذكيرات العمل.
- تشغيل مهام مزامنة خلفية.
- إعادة تجهيز المهام بعد إعادة تشغيل الجهاز.

## تدفق الاستخدام

### مستخدم جديد
`فتح التطبيق → إنشاء حساب → الإعداد الأولي → إنشاء المحل والشهر → مساحة العمل`

### مستخدم لديه حساب
`فتح التطبيق → استعادة الجلسة → تفعيل قاعدة بيانات الحساب → مزامنة → استعادة المحل/الشهر → مساحة العمل`

### مستخدم دون حساب
`فتح التطبيق → متابعة دون حساب → استخدام محلي`

### تسجيل الخروج
`مساحة العمل → تسجيل الخروج → تأكيد → حفظ البيانات المحلية → مسح الجلسة → شاشة الدخول`

عند تسجيل الدخول مرة أخرى بالحساب نفسه، يتم استخدام قاعدة بيانات الحساب نفسه بدل خلط بيانات الحسابات المختلفة.

## التخزين والمزامنة

يستخدم Pepers **SQLite كقاعدة العمل المحلية**، بينما تُستخدم Supabase للمصادقة والمزامنة السحابية.

الجداول الرئيسية في مخطط المزامنة تشمل:

- `user_profiles`
- `shops`
- `workers`
- `months`
- `pieces`
- `days`
- `entries`
- `individual_entries`
- `individual_entry_items`
- `assistants`
- `assistant_piece_rates`
- `assistant_daily_records`
- `assistant_withdrawals`

يستخدم التطبيق معرفات ثابتة للسجلات أثناء المزامنة لتقليل احتمالية تكرار السجلات بين الأجهزة.

مخطط قاعدة البيانات موجود في:

`supabase/migrations/20260911_pepers_sync_schema.sql`

وتعتمد جداول Supabase على **Row Level Security (RLS)** لعزل بيانات المستخدم المصادق عليه.

### ملاحظة أمنية
لا تضع مفتاح Supabase من نوع `service_role` داخل تطبيق Android أو المستودع. التطبيق يستخدم المفتاح العام المخصص للعميل فقط، بينما تبقى المفاتيح الإدارية خارج التطبيق.

## الصلاحيات

- `INTERNET` — المصادقة والمزامنة السحابية.
- `POST_NOTIFICATIONS` — إشعارات وتذكيرات العمل على Android 13+.
- `RECEIVE_BOOT_COMPLETED` — إعادة تجهيز المهام الخلفية بعد إعادة تشغيل الجهاز.

يستخدم التطبيق أيضًا `FileProvider` لمشاركة ملفات PDF بأمان مع التطبيقات الأخرى.

## الخصوصية والبيانات

- البيانات المحلية تبقى على الجهاز ما لم يقرر المستخدم مشاركتها أو مزامنتها.
- عند تسجيل الدخول والمزامنة، تُرفع بيانات الحساب إلى مشروع Supabase المهيأ للتطبيق.
- النسخ الاحتياطية وملفات PDF قد تحتوي على بيانات العمل والعملاء، لذلك يجب حفظها ومشاركتها بحذر.
- تسجيل الخروج لا يعني حذف قاعدة البيانات المحلية.
- لا يحتوي التطبيق على بيانات تجريبية مقصودة للمستخدم النهائي.
