# حساب الخياطين

> تطبيق Android عربي لإدارة حسابات محلات الخياطة وتسجيل الإنتاج والمصروفات بطريقة منظمة.

[![Kotlin](https://img.shields.io/badge/Kotlin-2.x-7F52FF?logo=kotlin&logoColor=white)](https://kotlinlang.org/) [![Android](https://img.shields.io/badge/Android-21%2B-3DDC84?logo=android&logoColor=white)](https://developer.android.com/) [![License](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

## نبذة عن التطبيق

حساب الخياطين هو تطبيق عربي موجّه لأصحاب محلات الخياطة والعاملين فيها. يساعدك على تنظيم المحلات والسجلات الشهرية، متابعة القطع والكميات، تسجيل المصروفات، وإصدار تقارير قابلة للمشاركة — كل ذلك من خلال واجهة عربية باتجاه من اليمين إلى اليسار.

يدعم التطبيق طريقتين مستقلتين للتسجيل حسب طبيعة العمل في كل محل:

- **التسجيل العددي:** مناسب لمتابعة الإنتاج اليومي حسب القطع والكميات والأسعار.
- **التسجيل الفردي:** مناسب عندما تحتاج إلى ربط كل عملية باسم الزبون ورقم الصفحة والكميات المسجلة.

## المزايا الرئيسية

- إدارة أكثر من محل، مع إعدادات تسجيل مستقلة لكل محل.
- إنشاء سجل شهري وتجهيز أيام الشهر تلقائيًا.
- تعريف قطع العمل وأسعارها وتعديلها عند الحاجة.
- تسجيل الإنتاج اليومي والمصروفات وبيان كل مصروف.
- عرض ملخصات الإنتاج والمصروفات والصافي وإجمالي القطع.
- تسجيل فردي بأسماء الزبائن وأرقام الصفحات والكميات حسب القطعة.
- بحث متسامح مع اختلافات الكتابة العربية، مثل الهمزات وبعض أشكال الحروف.
- نسخ شهر كامل لإنشاء سجل جديد بالإعدادات نفسها دون نسخ الكميات.
- إنشاء تقارير PDF ومشاركتها عبر واتساب أو البريد أو أي تطبيق يدعم المشاركة.
- قفل التطبيق برمز حماية من 4 إلى 8 أرقام.
- إنشاء نسخة احتياطية واستعادة البيانات عند الحاجة.
- نسخ احتياطي داخلي تلقائي عند تشغيل التطبيق.
- دعم الإشعارات لتذكيرات العمل على الإصدارات الحديثة من Android.
- واجهة عربية RTL مبنية باستخدام Jetpack Compose وMaterial 3.

## طريقة الاستخدام

### 1. الإعداد الأولي

عند تشغيل التطبيق لأول مرة، أدخل بياناتك الشخصية الأساسية. يمكنك حفظ الاسم وبيانات التواصل واسم المحل والصورة الشخصية لاستخدامها في التقارير والمشاركة.

### 2. إضافة محل

من القائمة الجانبية اختر إضافة محل جديد، ثم أدخل:

1. اسم المحل.
2. رقم المحل أو رقم التسجيل.
3. نوع الحساب: تسجيل عددي أو تسجيل فردي.

لكل محل إعداداته وسجلاته الشهرية الخاصة، ويمكن تغيير نوع التسجيل من إعدادات المحل لاحقًا.

### 3. إنشاء سجل الشهر

بعد اختيار المحل، أنشئ سجلًا للشهر بتحديد السنة ورقم الشهر. سيقوم التطبيق بإنشاء أيام الشهر تلقائيًا لتبدأ التسجيل مباشرة.

### 4. إعداد قطع العمل

أضف قطع العمل التي يتعامل معها المحل، مثل أنواع الملابس أو الخدمات، وحدد سعر كل قطعة. لا يمكن حذف قطعة مرتبطة بكميات مسجلة حتى لا تتأثر البيانات السابقة.

### 5. استخدام التسجيل العددي

في هذا الوضع يمكنك تسجيل كمية كل قطعة لكل يوم، وإضافة مصروف اليوم وبيانه. يعرض التطبيق تلقائيًا ملخصات الإنتاج والمصروفات والصافي، مع إجمالي مستقل لكل قطعة وإجمالي يومي شامل.

هذا الوضع مناسب للتسجيل السريع عندما لا تحتاج إلى حفظ تفاصيل كل زبون.

### 6. استخدام التسجيل الفردي

في هذا الوضع أضف حسابًا لكل زبون مع الاسم ورقم الصفحة والكميات المطلوبة من كل قطعة. يمكنك التنقل بين الأيام المسجلة والبحث باسم الزبون أو رقم الصفحة، كما يمكن تسجيل مصروف اليوم وملاحظته بشكل مستقل.

هذا السجل مستقل عن التسجيل العددي؛ اختر الوضع الأنسب للمحل عند إنشائه.

### 7. التقارير والمشاركة

من شاشة السجل أنشئ تقريرًا للشهر أو للتسجيل الفردي. يحوّل التطبيق التقرير إلى ملف PDF مؤقت ثم يفتحه عبر قائمة المشاركة في Android، لتتمكن من إرساله عبر واتساب أو البريد أو أي تطبيق آخر.

قبل مشاركة التقرير، احفظ بيانات الاسم ووسيلة التواصل إذا أردت ظهورها ضمن التقرير.

### 8. النسخ الاحتياطي والحماية

من إعدادات المحل افتح قسم **الحماية والنسخ الاحتياطي**:

- فعّل رمز حماية من 4 إلى 8 أرقام لمنع الوصول غير المصرح به.
- اختر إنشاء نسخة احتياطية لحفظ بيانات التطبيق في ملف ZIP تختار مكانه.
- استخدم الاستعادة لاسترجاع نسخة سابقة، ثم أعد فتح التطبيق بعد اكتمال العملية.
- احتفظ بالنسخة الاحتياطية في مكان آمن، ولا تشاركها مع أشخاص غير موثوقين لأنها قد تحتوي على بيانات الحسابات.

## بنية المشروع

```text
pepers/
├── app/
│   ├── module.toml
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── kotlin/com/add/pepers/
│       │   ├── MainActivity.kt          # نقطة تشغيل التطبيق
│       │   ├── WorkLogSheet.kt           # التدفق الرئيسي وإدارة المحلات والأشهر
│       │   ├── MainLedger.kt             # واجهة التسجيل العددي
│       │   ├── IndividualLedger.kt       # واجهة التسجيل الفردي
│       │   ├── Database.kt               # قاعدة البيانات والترحيلات
│       │   ├── SecurityBackup.kt         # القفل والنسخ الاحتياطي والاستعادة
│       │   ├── PdfUtils.kt               # إنشاء التقارير
│       │   ├── PdfShare.kt               # مشاركة ملفات PDF
│       │   └── cloud/CloudSync.kt        # نقطة توسعة للمزامنة السحابية
│       └── res/                          # الأيقونات والألوان والسمات
└── LICENSE
```

## المتطلبات التقنية

- Kotlin مع مستوى توافق Java 8.
- Android compile SDK 34 وtarget SDK 34.
- الحد الأدنى لإصدار Android هو API 21.
- Jetpack Compose 1.7.5 وMaterial 3 1.3.1.
- مساحة أسماء التطبيق: `com.add.pepers`.
- إعداد البناء موجود في `app/module.toml`.

يفضّل فتح المشروع في بيئة تطوير Android تدعم صيغة `module.toml` المستخدمة في هذا المستودع. لا يحتوي المستودع حاليًا على Gradle Wrapper، لذلك لا يضيف هذا الدليل أوامر `./gradlew` غير متاحة فعليًا.

## الخصوصية والبيانات

تُخزّن سجلات التطبيق محليًا على الجهاز. عند استخدام النسخ الاحتياطي أو مشاركة تقرير PDF، تصبح نسخة من البيانات موجودة في المكان الذي تختاره أو في التطبيق الذي تشارك الملف معه. راجع محتوى النسخة قبل إرسالها.

يطلب التطبيق إذن الإشعارات على Android 13 والإصدارات الأحدث لتفعيل تذكيرات العمل. يمكن إدارة الإذن من إعدادات النظام.
