# إعداد المصادقة والمزامنة في Pepers

التطبيق يستخدم البريد الإلكتروني وكلمة المرور، وتسجيل الدخول باستخدام Google عبر Supabase Auth. لا توجد شاشة أو منطق لرمز التحقق أو OTP.

## Supabase Auth

1. فعّل Email provider في Authentication → Providers → Email.
2. فعّل Google provider وأدخل بيانات OAuth الخاصة بتطبيقك.
3. أضف URI العودة التالي في Authentication → URL Configuration → Redirect URLs:

pepers://auth/callback

التطبيق يفتح OAuth من Supabase ثم يعود إلى Android عبر هذا الرابط ويحفظ جلسة Auth للمزامنة.

إذا كان Confirm email مفعّلًا، يجب على المستخدم فتح رسالة التأكيد مرة واحدة قبل أول دخول بالبريد وكلمة المرور. Google لا يحتاج مسار OTP.

## SQLite والمزامنة

SQLite هي قاعدة البيانات المحلية ومصدر العمل دون إنترنت. Supabase PostgreSQL هو النسخة السحابية. المزامنة تعمل عند فتح التطبيق، بعد تغييرات البيانات، عند توفر الشبكة، وبشكل دوري عبر WorkManager مع إعادة المحاولة عند فشل الاتصال.

طبّق ملفات supabase/migrations على مشروع Supabase. جداول المزامنة مربوطة بـ auth.users(id)، وسياسات RLS تقصر القراءة والكتابة على auth.uid() للمستخدم الحالي.

## صور الملف الشخصي

صور الملف الشخصي تُرفع إلى bucket خاص باسم profile-images داخل Supabase Storage بمسار يبدأ بـ user ID، مع سياسات RLS تمنع المستخدم من قراءة أو تعديل صور مستخدم آخر. يحتفظ التطبيق بنسخة محلية للعرض دون إنترنت.

## الإشعارات والتذكيرات

التطبيق يطلب إذن POST_NOTIFICATIONS على Android 13+ فقط عند الدخول إلى مساحة العمل. التذكير اليومي يعاد جدولته بعد إعادة تشغيل الجهاز، ولا يستخدم صلاحية المنبه الدقيق.
