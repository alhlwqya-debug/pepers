# إعداد رموز التحقق

التطبيق يستخدم Supabase Auth عبر واجهة OTP، ولا يحتاج إلى كلمة مرور للمستخدم.

## البريد الإلكتروني

من لوحة Supabase افتح:

`Authentication → Email Templates → Magic Link`

استبدل محتوى الرسالة برسالة تحتوي على الرمز:

```html
<h2>رمز التحقق لحساب الخياطين</h2>
<p>استخدم الرمز التالي لإكمال الدخول:</p>
<p style="font-size: 32px; font-weight: bold;">{{ .Token }}</p>
<p>صلاحية الرمز محدودة. إذا لم تطلبه فتجاهل هذه الرسالة.</p>
```

لا تستخدم رابط `{{ .ConfirmationURL }}` إذا كان المطلوب إدخال رمز داخل التطبيق.

## الهاتف

من لوحة Supabase افتح:

`Authentication → Providers → Phone`

فعّل مزود الرسائل النصية وأدخل بيانات مزود SMS. يجب أن يرسل المزود الرقم بصيغة دولية، مثل:

`+9677XXXXXXX`

تطبيق أندرويد لا يحتوي على `service_role` ولا يتجاوز إعدادات Supabase؛ المفتاح الموجود في التطبيق هو publishable key فقط.

في إعدادات المشروع الحالية، البريد الإلكتروني مفعّل، بينما الهاتف يحتاج إلى تفعيل مزود SMS قبل أن تعمل رسائل الهاتف.

## سلوك التطبيق

- **إنشاء حساب** يرسل رمزًا مع `create_user: true`.
- **تسجيل الدخول** يرسل رمزًا مع `create_user: false`.
- بعد التحقق يحفظ التطبيق جلسة Supabase محليًا ويستعيدها عند فتح التطبيق.
- زر **متابعة دون حساب** يبقي مسار الاستخدام المحلي متاحًا.
